My personal portfolio website, built to show who I am, what I build, and how to reach me.

**Live site:** https://kwizera-salim.vercel.app/

## Features

- Responsive layout for phones, tablets and computers
- Mobile navigation menu
- Typing effect in the hero section
- Scroll reveal animations
- Project cards generated from a JavaScript array

## Built with

- HTML
- Tailwind CSS
- JavaScript
- Vite

## Run it locally

```
git clone https://github.com/salimbuilds/portfolio-v1.git
cd portfolio-v1
npm install
npm run dev
```

Then open the address shown in the terminal.
